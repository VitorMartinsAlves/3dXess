Perguntas frequentes

O jogo é gratuito?

Sim. O 3dXess pode ser usado gratuitamente no navegador.

Preciso criar uma conta?

Não. As partidas não exigem cadastro. O progresso dos exercícios fica salvo localmente neste navegador.

Como funciona o modo online?

As partidas usam conexão entre navegadores via WebRTC. O anfitrião precisa permanecer conectado durante a partida.
